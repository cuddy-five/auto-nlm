# Scout

**status:** exploratory

Details live in `docs/OUTLINE.md`.

We are trying a **small pydantic classification** (categories + observations) plus **short LLM instructions**, so the host can tell what kind of question the user asked and brief Tavily more clearly.

The host does **not** invent the sub-topic map. Tavily names the parts.

How we classify, which Tavily mode we pick, and the brief shape are **not locked**.
